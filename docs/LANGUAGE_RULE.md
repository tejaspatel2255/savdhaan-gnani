# English-First Language Rule

English is the PRIMARY language of the entire Savdhaan product.

1. **Primary Interface**: All user-facing headings, button labels, statuses,
   warnings, and explanatory descriptions must have English as their primary
   visible text.
2. **Secondary Local Language**: Hindi (or Gujarati, when selected by the
   language chip) appears exclusively as a smaller, styled secondary line
   or span (`.t-loc`), never as the sole language.
3. **No Indic-Only Comprehension**: Nothing a visitor needs to read or understand
   the interface may exist only in Hindi or Gujarati.
4. **Spoken Warnings**: Spoken voice alerts in Indic languages are accompanied
   by prominent primary English warning text on-screen.
5. **Transcripts & Calls**: Audio transcripts in Indian languages display
   corresponding English translation glosses directly on the Tape slips.
6. **Code & Events**: Backend event payloads carry English messages
   (`message_en` or English equivalents) alongside local text.
