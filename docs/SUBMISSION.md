## 1. 90-Word Project Description

Savdhaan is an explainable, real-time scam-call shield protecting Indian citizens against digital arrest, OTP theft, and financial fraud. Streaming live audio to Gnani Prisma v2.5 for instant speech recognition, it evaluates rolling bilingual transcripts against rule packs tracking pressure, impersonation, and payment demands. When danger strikes, Savdhaan triggers an interactive evil-eye control room, speaks a localized warning via Gnani Timbre v3.0, and simulates alerts to family members before money is lost. All metrics are transparently published in an auditable ledger without manual estimations.
